### Measured cross-checks & prompt rules (added 24-09-2026, RU+IAST book scans)

From a 7-approach benchmark on Russian scholarly scans with IAST (Shcherbatskoi corpus; Stch.pdf 53 pp + 1922 97 pp; full table: Uprava [`tools/ocr_vlm/README.md`](https://github.com/gasyoun/Uprava/blob/main/tools/ocr_vlm/README.md), recipe Uprava [`RECIPES §25`](https://github.com/gasyoun/Uprava/blob/main/RECIPES.md)):

- **Model lane, measured**: `qwen3-vl-plus` (DashScope) beat every local option on IAST diacritics — 232 diacritic marks on Stch vs 166 (gemini-2.5-flash), **0** for Tesseract `rus`/`rus+eng` (tess-`rus` maps Latin to Cyrillic lookalikes: «ТЬе СопсерЕ1оп») and **0** for the embedded Acrobat layer. The crop-band Read technique above stays primary for CSDL front matter; the API lane (`Uprava/tools/ocr_vlm/batch_book2.py`) is the validated fallback and the primary for whole Cyrillic/IAST bodies. 4.05 s/page effective (4 workers); ≈$0.15 per 97-pp book paid-equivalent, ≈$1.5/1000 pp (new-account free quota 1M tok/90 d covers a book).
- **Prompt rules that measurably mattered**: diacritic ending-anchors in the prompt (Śūnyatā→`-tā`, Madhyānta→`-ānta`, Nirvāṇa→`-vā-`) — without them two of four VLMs dropped final macrons; negative rule «quotations are roman unless the single word leans» (without it models italicize whole quoted passages); Cyrillic pre-reform rule (ѣ/ъ/і/фіта verbatim, never modernize — verified ѣ×2067/ъ×5976 on the 1922 print with zero modernization); footnote defs arrive as `[^8] text` and need the `(?m)^\[\^(\d+[a-z]*)\] ` → `[^8]: ` repair at assembly.
- **Traps**: image-only pages (portraits) → prompt-echo hallucination (the model transcribes YOUR prompt — detect by prompt phrases in the output, replace with an honest page description); `content: None` responses → retry the page; a crashed run leaves empty shell files that a file-exists cache then treats as done — purge `*.md` size-0 before resuming.
