## Documentation rule — tracking-issue results (23-07-2026)

Census, pilot, Engine A/B comparison, and pref-abbr×body tables that are tracked by a
**named GitHub issue** (e.g. [csl-guides#123](https://github.com/sanskrit-lexicon/csl-guides/issues/123))
must get a **results comment on that issue in the same pass** — not only a PR or
`scripts/out/` commit. Minimum: handoff ID + PR URL + summary table + non-goals +
reproduce. Full contract: [`persist-tables.md`](https://github.com/gasyoun/claude-config/blob/main/references/persist-tables.md)
§ "Also on the tracking GitHub issue". Pilot and scale-all each post their **own**
comment; do not wait for merge.
